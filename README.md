# Aurora Forge – Audio Visualizer

A single-page, build-free audio visualizer that runs entirely in the browser. Drop a track, pick a mode, and enjoy reactive neon visuals.

## Usage
1. Open `index.html` in a modern browser (Chrome, Edge, Firefox).
2. Choose a local audio file (mp3, wav, ogg).
3. Press **Play** and switch between the visual modes.
4. Use the **Full screen** button for stage-friendly visuals.

## Visual Modes
- **Neon Bars**: Gradient vertical bars with a glowing base line.
- **Halo Ring**: Radial spikes orbiting the center with an inner pulse ring.
- **Liquid Blob**: Organic blob that warps and glows with the music.
